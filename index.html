How to Use

  1. Open this page over HTTPS.
  2. Press ▶️ READY and allow camera and location permission.
  3. Use 🔄 to switch between rear and front cameras.
  4. Use 🔦 to switch flashlight OFF/ON when supported.
  5. Use ➖ and ➕ to change zoom.
  6. Enter Additional Information or Visited By if needed.
  7. The supplied camera/location photo is the default badge and app icon. Upload another logo only if you want to replace it.
  8. Press 📸. The final JPG is generated and downloaded automatically.

Install as App / Shortcut

Android Chrome

Open the HTTPS page → ⋮ → Install app or Add to Home screen.

iPhone / iPad Safari

Open the HTTPS page → Share → Add to Home Screen → Add.

Desktop Chrome / Edge

Use Install or Create shortcut from the browser menu.

Important: Camera and GPS require HTTPS.
